AI環境 点検票

Claude Code や Codex を自分で使う経営者のAI環境を、7分野・30項目で点検します。点検は読み取り専用で行い、設定の変更はお客様ご自身が行います。

0使い方

  1. 診断用の指示文をお客様に渡す
    下の「診断用の指示文」をコピーして渡します。お客様は、Claude Code のデスクトップアプリか Codex アプリで普段の作業フォルダを開き、新しい会話に指示文を貼り付けて送るだけです。モードの切り替えは必須にしていません（確実にしたい方向けの手順は、下の補足に残しています）。
    確認の画面が出たら、内容が一覧の表示・検索・読み取りなら許可し、変更・削除・インストール・送信なら許可せずに止めてもらいます（「今後は確認しない」のような選択肢は選ばないでもらいます）。
    補足：ターミナルで使う方は、Claude Code は claude --permission-mode plan、Codex は codex --sandbox read-only で起動してから貼り付けます。
  2. 必要事項を書き、JSON を入れてレポートを作る
    お客様には、秘密情報の値が含まれていないことを確かめてから送ってもらいます。AIの回答は、JSON ファイルに保存しても、そのまま貼り付けてもかまいません。「レポートを作成」を押すと、判定と確かめた事実がレポートに反映されます。
  3. 聞き取りで埋め、判定を確かめる
    レポートの「聞き取りで確かめること」は、30分のオンライン面談で本人に聞いて埋めます。AIの判定は提案なので、点検者が最終判定を付けます。
  4. 改修用の指示文で直す
    「点検結果をもとに改修用の指示文を作成」を押すと、赤と黄の項目を直す指示文がクリップボードにコピーされます。普段使っているAIの新しい会話に貼ると、AIが1項目ずつ内容を見せ、承認された項目だけを直します。
  5. 結果を書き出して渡す
    「印刷・PDF」でお客様に渡す点検結果になります。チャット用の文面と、保管用の JSON も書き出せます。レポートには、見つかったタスク名やサービス名などが残ります。お客様以外に見せる前に、社名・取引先名などが入っていないか確かめてください。
点検の前に、お客様へ伝えておくこと
  • 「普段の作業フォルダ」とは、お客様が Claude Code や Codex で仕事をするときに、いつも開くフォルダのことです（案件ごとのフォルダ）。ホームフォルダ・デスクトップ・ドライブ直下は、作業フォルダとして扱いません。そこで開いて点検すると、一覧と検索をせず、聞き取りになります。
  • 作業フォルダの中のファイル名は、AIに渡ります（一覧と検索のため）。中身を検索するのは、スクリプト・設定・指示書だけで、一致したファイル名だけを返す決めです。名簿や資料、鍵のファイルの中身は検索しません。
  • 「読み取りだけ」「秘密情報の値は出さない」は、AIへの指示です。仕組みでの保証ではありません。AIが確認なしで動ける状態でも、指示は同じですが、守られることを機械的に確かめてはいません。確認の画面が出るときは、お客様自身が許可するかどうかを選べます。
診断用の指示文（お客様に渡すもの）
この指示文は、AIに「読み取りだけ」「秘密情報の値は出さない」を守らせる内容です。点検者が内容を書き換えるときも、この2つは消さないでください。

次にすること

  1. Claude Code か Codex で普段の作業フォルダを開き、新しい会話に貼り付けて送ります。
  2. AIが変更の内容を1項目ずつ見せるので、確かめて「はい」か「飛ばして」で答えます。
  3. 終わったら診断用の指示文をもう一度実行し、JSON を入れ直すと、直ったかどうかを確かめられます。
